# Phoenix Swinger 2.0

High-Probability Deep Base Breakouts & Dynamic Swing Portfolio for Indian Equities.

## Key Strategy Mechanics
1. **Universe Filtering**: Market Cap ≥ ₹2,000 Cr, Daily ATR ≥ 3.2%
2. **Dual-Leg Entry**:
   - **Leg 1**: Fresh multi-month deep base breakouts confirmed by volume.
   - **Leg 2**: 50% retracement retest of breakout level / 20 EMA bounce.
3. **Automated Risk Shielding**:
   - Structural Stop Loss: **-15%**
   - Cost Shield (Break-Even): Auto-locks SL to entry price at **+15%** profit.
   - Runner Mode: **25%** trailing stop from peak for compounding multi-bagger runners.
